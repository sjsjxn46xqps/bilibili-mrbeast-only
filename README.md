# B站只看野兽先生 · MrBeast Only

一个 Microsoft Edge / Chromium 的 **Manifest V3** 扩展：把哔哩哔哩首页变成 **MrBeast（野兽先生）专属内容墙**，并把搜索限定为野兽先生相关内容。

> 非官方扩展，与哔哩哔哩、MrBeast 均无隶属关系。
>
> **本项目由 AI 辅助制作，可能存在瑕疵。** 使用前请自行验证；遇到问题欢迎反馈。

## 功能

- **首页接管**：隐藏 B 站首页原有推荐流，支持 `/`、`/zh-Hans/`、`/zh-Hant/`、`/en/` 等语言首页。
- **官方全量**：通过 B 站空间接口分页读取官方主频道公开投稿（当前 122 个）。
- **内容漏斗**：`全部` / `官方` / `搬运 · 翻译` / `搬运 · 未翻译`。
- **二创开关**：
  - “全部包含二创”：AI、解说、模仿、低播放等进入“全部”最底部；
  - “全量关键词”子开关：所有含“野兽先生 / MrBeast”且 ≥500 播放的非官方视频都放到底部。
- **搜索接管**：搜索栏自动拼成“野兽先生 + 关键词”；搜索页置顶官方账号卡，下面只显示筛选后的内容。
- **刷新与滚动**：刷新按钮支持加载中排队；首页和搜索页鼠标滚轮正常。
- **响应式**：视频墙 4 / 3 / 2 / 1 列切换。
- **隐私**：不收集数据，不包含统计、广告或远程代码。

## 安装

### 从源码加载（开发/未打包）

```bash
git clone https://github.com/<你的用户名>/bilibili-mrbeast-only.git
```

1. 打开 Edge，地址栏输入 `edge://extensions/`。
2. 打开左下角 **开发人员模式**。
3. 点击 **加载解压缩的扩展**，选择仓库文件夹。
4. 打开或刷新 [哔哩哔哩首页](https://www.bilibili.com/)。
5. 在弹窗中确认版本为 **1.4.1**。

### 从 Release ZIP 安装

1. 下载 Release 中的 `bilibili-mrbeast-only-v1.4.1.zip` 并解压。
2. 在 `edge://extensions/` 中加载解压后的文件夹。

> 更新后请在 `edge://extensions/` 点击该扩展的 **重新加载**，然后 `Ctrl + F5` 刷新 B 站。

## 使用

- **内容分类**：在首页/搜索页切换“全部 / 官方 / 搬运 · 翻译 / 搬运 · 未翻译”。
- **二创开关**：点击工具栏扩展图标，打开“全部包含二创”；需要时再开“全量关键词”。
- **刷新**：首页右上角、Hero 按钮或弹窗“刷新视频”；加载中点击会排队。
- **搜索**：B 站搜索栏输入普通词，自动限定为“野兽先生 + 关键词”。

## 说明：哪些是“全部”？

- **官方区是全量**：通过空间接口读取公开投稿；如果接口触发风控，会退回搜索结果并在页面提示。
- **搬运区不是全站全部**：B 站没有公开“全站所有搬运视频”的统一列表，只能读取搜索可见结果。
- **二创/其他**：开启“全部包含二创”后进入“全部”底部；低播放过滤阈值为 500。
- **全量关键词**：开启后，所有含关键词且 ≥500 播放的非官方视频排到底部；官方仍置顶。

## 权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存开关状态和视频缓存 |
| `activeTab` | 识别当前 B 站标签页，用于重新接管首页/搜索页 |
| `scripting` | 页面早于扩展加载时补注入内容脚本 |
| `declarativeNetRequestWithHostAccess` | 仅给 B 站空间/搜索 API 补充来源头，避免风控 |
| `https://*.bilibili.com/*` | 在 B 站首页/搜索页运行，并请求 B 站公开接口 |

详见 [PRIVACY.md](PRIVACY.md)。

## 开发

```bash
# 修改 content/、search/ 后
# 1. edge://extensions/ 重新加载扩展
# 2. 刷新 B 站
```

结构：

```text
bilibili-mrbeast-only/
├─ manifest.json
├─ background.js          # 自愈注入 + WBI 空间/搜索 API 代理
├─ content/               # 首页接管、分类、搜索栏限定
├─ search/                # 搜索页官方账号卡与结果
├─ lib/                   # MD5 / WBI 签名
├─ rules/                 # 仅 B 站 API 的来源头规则
├─ popup/                 # 扩展弹窗与两个开关
├─ icons/
├─ docs/                  # 预览图
├─ README.md
├─ PRIVACY.md
├─ LICENSE
└─ PUBLISH.md
```
